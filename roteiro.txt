# ROTEIRO DE AUTOMAÇÃO WHATSAPP - XPS247
## Fluxo Completo de Transferência Internacional

### 📱 PONTO DE PARTIDA
O cliente envia qualquer mensagem para iniciar o atendimento (ex: "Olá", "Quero enviar dinheiro", etc.)

---

## ETAPA 1: IDENTIFICAÇÃO DO CLIENTE

### 🔍 Verificação Automática
**Sistema verifica:** Número do telefone existe no banco de dados?

**Se CLIENTE CADASTRADO:**
- Sistema recupera nome e dados do cliente
- Busca cotação atual do dólar
- Prossegue para **ETAPA 2A** (Cliente Existente)

**Se CLIENTE NOVO:**
- Cliente não possui cadastro
- Prossegue para **ETAPA 2B** (Novo Cliente)


---

## ETAPA 2A: BOAS-VINDAS - CLIENTE EXISTENTE

### 💬 Mensagem do Sistema
```
Olá, [Nome do Cliente]! Que bom ter você aqui novamente.
A cotação do dólar hoje para envio é de R$ [Valor da Cotação].

Você deseja iniciar uma transferência?
1 - Sim, quero fazer uma transferência
2 - Não, obrigado
```

### 🔄 Fluxo de Respostas

**Se digitar "1":**
- Prossegue para **ETAPA 3** (Autenticação)

**Se digitar "2":**
```
Entendido. Se precisar de ajuda ou quiser falar com nossos atendentes, me avise.
Obrigado pelo contato!
```
- **FIM DO ATENDIMENTO**

**Se resposta inválida:**
```
Opção inválida. Por favor:
1 - Para iniciar transferência
2 - Para cancelar
```

## ETAPA 2B: BOAS-VINDAS - CLIENTE NOVO

### 💬 Mensagem do Sistema
```
Olá! Bem-vindo(a) à XPS247! 🇺🇸➡️🇧🇷

2 - Não agora
```

### 🔄 Fluxo de Respostas

**Se digitar "1":**
- Prossegue para **ETAPA 4** (Cadastro)

```
Tudo bem! Quando estiver pronto, é só me chamar.
Salve nosso número para facilitar o contato. Obrigado!
```

## ETAPA 3: AUTENTICAÇÃO SEGURA

### 🔐 Processo de Login

**Passo 1 - Usuário:**
```
Para sua segurança, faça o login.
Insira seu nome de usuário ou e-mail cadastrado:
```

**Passo 2 - Senha:**
```
Obrigado. Agora, insira sua senha:
```

### ✅ Validação das Credenciais

**Se LOGIN VÁLIDO:**
```
Login realizado com sucesso! ✅
Vamos iniciar sua transferência.
```
- Prossegue para **ETAPA 5** (Dados da Operação)

**Se LOGIN INVÁLIDO:**
```
Usuário ou senha incorretos. ❌

1 - Tentar novamente
2 - Esqueci minha senha
```

### 🔄 Opções de Recuperação

**Se digitar "1":**
- Retorna ao início da **ETAPA 3**

**Se digitar "2":**
```
Para redefinir sua senha, informe o e-mail do seu cadastro:
```

**Se e-mail EXISTE:**
```
Enviamos um link seguro para: [e-mail do cliente]
Verifique sua caixa de entrada e spam.
Após criar nova senha, volte aqui e me chame para continuar.
```
- **FIM DO ATENDIMENTO**

**Se e-mail NÃO EXISTE:**
```
E-mail não encontrado. Tente novamente ou entre em contato conosco.
```
- **FIM DO ATENDIMENTO**

---

## ETAPA 4: CADASTRO SIMPLIFICADO

### 📝 Coleta de Dados Básicos

**Passo 1 - Nome:**
```
Ótimo! Para começar, qual o seu nome completo?
```

**Passo 2 - Username:**
```
Prazer, [Nome do Cliente]! 😊
Agora, crie um nome de usuário:
```

**Passo 3 - Cadastro Completo:**
```
Perfeito! Para finalizar o cadastro, precisamos de mais alguns dados
em nosso site seguro para cumprir as regulamentações.

Por favor, acesse o link abaixo:
[Link para página de cadastro da XPS247]

Após finalizar, volte aqui e digite "Pronto" para iniciarmos
sua primeira transferência!
```

### ⏳ Aguardando Confirmação
**Sistema aguarda:** Cliente digitar "Pronto"
**Quando confirmado:** Prossegue para **ETAPA 5** (Dados da Operação)

---

## ETAPA 5: DADOS DA TRANSFERÊNCIA

### 👤 Informações do Destinatário

```
Excelente! Agora vamos coletar os dados da pessoa que
irá receber o dinheiro no Brasil.
```

**Passo 1 - Nome:**
```
1. Qual o Nome Completo do destinatário?
```

**Passo 2 - CPF:**
```
2. Qual o CPF do destinatário?
(Use apenas números: 12345678900)
```

**Passo 3 - Chave PIX:**
```
3. Qual a Chave PIX para recebimento?
(Pode ser: CPF, e-mail, telefone ou chave aleatória)
```

**Passo 4 - Endereço:**
```
4. Informe o endereço completo no formato:
Rua/Avenida, Número, Complemento, Bairro, Cidade - Estado, CEP

Exemplo: Rua das Flores, 123, Apt 45, Centro, São Paulo - SP, 01234-567
```

### 💰 Valor da Transferência

```
Dados do destinatário recebidos! ✅

Agora, quanto você deseja transferir em DÓLARES (USD)?
Exemplo: 150.00
```

### 🧮 Cálculo Automático
**Sistema processa:**
- Valor em USD informado
- Cotação atual do dólar
- Cálculo de taxas
- Valor final em Reais (BRL)

---

### 📋 Resumo da Operação

```
📊 RESUMO DA SUA TRANSFERÊNCIA:

💵 VALORES:
• Você envia: $ [Valor em USD]

👤 DESTINATÁRIO:
• Nome: [Nome do Destinatário]
• CPF: [CPF do Destinatário]
• Chave PIX: [Chave PIX]

✅ Os dados estão corretos?
1 - Sim, tudo correto
2 - Não, quero alterar
```

### 🔄 Opções de Confirmação

**Se digitar "1":**
- Prossegue para **ETAPA 7** (Pagamento)

**Se digitar "2":**
```
O que você gostaria de fazer?
1 - Alterar dados da operação
2 - Cancelar atendimento
```

**Se escolher "1" (Alterar):**
- Retorna para **ETAPA 5** (Dados da Operação)

**Se escolher "2" (Cancelar):**
```
Operação cancelada. Se mudar de ideia, estarei por aqui! 😊
```
- **FIM DO ATENDIMENTO**

## 📝 RESUMO DO FLUXO COMPLETO

1. **IDENTIFICAÇÃO** → Verificar se cliente existe
2. **BOAS-VINDAS** → Mensagem personalizada (existente/novo)
3. **AUTENTICAÇÃO** → Login seguro (apenas clientes existentes)
4. **CADASTRO** → Registro simplificado (apenas novos clientes)
5. **DADOS DA OPERAÇÃO** → Destinatário e valor
6. **CONFIRMAÇÃO** → Revisão de todos os dados
7. **PAGAMENTO** → Processamento e finalização

### 🎯 PONTOS DE SAÍDA
- Cliente recusa cadastro/transferência
- Falha na autenticação
- Cancelamento durante confirmação
- Conclusão bem-sucedida da transferência
