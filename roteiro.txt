Roteiro de Automação WhatsApp para XPS247 - Árvore de Decisão
Este roteiro descreve o fluxo de interação do cliente desde o primeiro contato até a finalização de uma transferência de dinheiro.

- Ponto de Partida: O cliente envia qualquer mensagem para o número de WhatsApp da empresa (ex: "Olá", "Quero enviar dinheiro", etc.).

# Nó 1: Verificação Inicial do Cliente
O sistema é acionado e executa a primeira verificação.

- Lógica do Sistema: [API] Verificar se o número de telefone do remetente já existe no banco de dados da XPS247.

- Se SIM (Cliente já cadastrado): O sistema recupera o nome do cliente e a cotação atual do dólar. Prossiga para o Nó 2.1.

- Se NÃO (Novo cliente): O cliente é novo ou nunca se identificou. Prossiga para o Nó 2.2.


# Nó 2: Mensagem de Boas-Vindas
## Nó 2.1: Mensagem para Cliente Existente
- Sistema: Olá, [Nome do Cliente]! Que bom ter você aqui novamente.
- A cotação do dólar hoje para envio é de R$ [Valor da Cotação].

- Sistema: Você deseja iniciar uma transferência?
1 - Sim
2 - Não

- Se o cliente digitar 1: Vá para o Nó 3 (Autenticação).

- Se o cliente digitar 2:

- Sistema: Entendido. Se precisar de ajuda com outro assunto ou quiser falar com um de nossos atendentes, me avise. Obrigado pelo contato!
(Fim do fluxo)

- Se a resposta for inválida:

- Sistema: Opção inválida. Por favor, digite 1 para iniciar uma transferência ou 2 para cancelar.

# Nó 2.2: Mensagem para Novo Cliente
- Sistema: Olá! Bem-vindo(a) à XPS247, sua forma rápida e segura de enviar dinheiro dos EUA para o Brasil. Para começarmos e garantir sua segurança, precisamos realizar um breve cadastro. Vamos lá?
1 - Sim, quero me cadastrar
2 - Não agora

- Se o cliente digitar 1: Vá para o Nó 4 (Fluxo de Cadastro).

- Se o cliente digitar 2:

- Sistema: Tudo bem! Quando estiver pronto, é só me chamar. Salve nosso número para facilitar o contato. Obrigado!
(Fim do fluxo)

# Nó 3: Autenticação do Cliente Existente
- Sistema: Para sua segurança, por favor, faça o login.
- Insira seu nome de usuário ou e-mail cadastrado:

- Cliente: [Insere o usuário/e-mail]

- Lógica doSistema: Obrigado. Agora, por favor, insira sua senha:

- Cliente: [Insere a senha]

- Lógica do Sistema: [API] Validar as credenciais (usuário/e-mail e senha) no banco de dados.

- Se as credenciais forem VÁLIDAS:

- Sistema: Login realizado com sucesso! Vamos iniciar sua transferência.
- Prossiga para o Nó 5 (Coleta de Dados da Operação).

- Se as credenciais forem INVÁLIDAS:

- Sistema: Usuário ou senha incorretos.
1 - Tentar novamente
2 - Esqueci minha senha

- Se o cliente digitar 1: Retorne ao início do Nó 3.

- Se o cliente digitar 2:

- Sistema: Para redefinir sua senha, por favor, informe o e-mail que você usou no cadastro.

- Cliente: [Insere o e-mail]

- Lógica do Sistema: [API] Verifica se o e-mail existe e envia um link para redefinição.

- Se o e-mail existir:

- Sistema: Enviamos um link seguro para redefinição de senha para o e-mail [e-mail do cliente]. Por favor, verifique sua caixa de entrada e spam. Após criar uma nova senha, volte aqui e me chame para continuar.
(Fim do fluxo de redefinição)

- Se o e-mail não existir:

- Sistema: Erro interno. Tente novamente.
(Fim do fluxo)

# Nó 4: Fluxo de Cadastro (Para Novos Clientes)
(Este fluxo pode ser simplificado no WhatsApp para coletar apenas o essencial e talvez completar em um link externo por segurança).

- Sistema: Ótimo! Para começar, qual o seu nome completo?

- Cliente: [Insere o nome completo]

- Lógica do Sistema: Prazer, [Nome do Cliente]! Agora, por favor, crie um nome de usuário:

- Cliente: [Insere o nome de usuário]

- logica do Sistema: Perfeito. Para finalizar o cadastro, precisamos de mais alguns dados em nosso site seguro para cumprir as regulamentações. Por favor, acesse o link abaixo para completar seu perfil.
[Link para a página de cadastro da XPS247]

- Após finalizar, volte aqui e digite "Pronto" para iniciarmos sua primeira transferência!
(O fluxo aguarda a confirmação do cliente para prosseguir para o Nó 5)

# Nó 5: Coleta de Dados da Operação
- Sistema: Excelente! Agora, por favor, informe os dados da pessoa que irá receber o dinheiro no Brasil.

- Sistema: 1. Qual o Nome Completo do destinatário?

- Cliente: [Insere o nome]

- Sistema: 2. Qual o CPF do destinatário? (Use apenas números)

- Cliente: [Insere o CPF]

- Sistema: 3. Qual a Chave PIX para o recebimento? (Pode ser CPF, e-mail, telefone ou chave aleatória)

- Cliente: [Insere a Chave PIX]

- Sistema: 4. Por favor, informe o endereço completo do destinatário no formato:
Rua/Avenida, Número, Complemento (se houver), Bairro, Cidade - Estado, CEP

- Cliente: [Insere o endereço no formato solicitado]

- Lógica do Sistema: Dados do destinatário recebidos! Agora, para o valor:
Quanto você deseja transferir em DÓLARES (USD)?

- Cliente: [Insere o valor, ex: 150.00]

- Lógica do Sistema: [API] O sistema captura o valor em USD, busca a cotação atual, calcula as taxas e o valor final em Reais (BRL).

- Sistema: Por favor, confirme todos os dados da sua operação:

- Sistema: Você envia: $ [Valor em USD]
- Sistema:Cotação do Dólar: R$ [Cotação]
- Sistema:Valor bruto: R$ [Valor convertido em BRL]
- Sistema:Taxa de serviço: R$Valor a receber no Brasil (aproximado): R$ [Valor convertido em BRL]

- Recebedor:
• Nome: [Nome do Destinatário]
• CPF: [CPF do Destinatário]
• Chave PIX: [Chave PIX do Destinatário]

- Os dados estão corretos?
1 - Sim, tudo correto
2 - Não, quero alterar

- Logica do sistema: Se o cliente digitar 1: Vá para o Nó 6 (Pagamento).

- Logica do sistema: Se o cliente digitar 2:

- Sistema: O que você gostaria de fazer?
1 - Alterar os dados da operação
2 - Cancelar e finalizar o atendimento

- Se digitar 1: Retorne ao início do Nó 5.

- Se digitar 2:

- Sistema: Operação cancelada. Se mudar de ideia, estarei por aqui!
(Fim do fluxo)

# Nó 6: Pagamento e Finalização
- Sistema: Perfeito! Para finalizar, gerei um link de pagamento seguro para você. Ele é válido por 20 minutos.

- Clique aqui para pagar: [Link único e seguro para o gateway de pagamento]

- logiga do sistema:Após a confirmação do pagamento, você receberá uma mensagem automática aqui mesmo.

- Lógica do Sistema: O sistema aguarda um webhook (notificação automática) do gateway de pagamento informando sobre o status da transação.

- Após receber a confirmação de pagamento bem-sucedido:

- Sistema: ✅ Pagamento Confirmado! Sua transação foi concluída com sucesso.

- O dinheiro estará na conta do(a) [Nome do Destinatário] em até [Definir tempo, ex: 1 dia útil]. Enviaremos uma nova mensagem assim que o valor for creditado.

- Deseja realizar outra transação?
1 - Sim, fazer outra transferência
2 - Não, finalizar agora

- Se o cliente digitar 1: Retorne ao Nó 5 (Coleta de Dados da Operação).

- Se o cliente digitar 2:

Sistema: Obrigado por utilizar a XPS247! Estamos sempre à disposição. Tenha um ótimo dia!
(Fim do fluxo)
